## Sobre mí 🚗💻

¡Bienvenido/a a mi portafolio! 

Mi trayectoria comenzó bajo el rigor de los estándares de calidad IATF 16949, donde aprendí una verdad absoluta: en la ingeniería de sistemas críticos, un error no detectado no es solo un "bug", es un riesgo real. Hoy, traslado esa misma disciplina analítica al ecosistema de software como QA Engineer, fusionando la precisión de la manufactura con la agilidad del testing moderno.

¿Qué valor diferencial aporto a los equipos de tecnología?

🔹 Diagnóstico de Raíz (RCA) & Caja Gris: Aplico metodologías industriales (Core Tools, 5S, Kaizen) e inspección en bases de datos para identificar fallos de lógica y estructura más allá de la superficie de la UI.

🔹 Testing de Alta Exigencia & UX/UI: Diseño y ejecuto planes de prueba (Manual & Automatización) en entornos de desarrollo y producción, asegurando tanto la estabilidad del sistema como una experiencia óptima para el usuario final.

🔹 Automatización e Integraciones: Desarrollo scripts y flujos eficientes (n8n, Python, Selenium) no solo para "probar", sino para optimizar procesos de regresión y acelerar ciclos de entrega mediante herramientas con IA.
🛠️ Mi Stack de Calidad Híbrido:

Software Testing: Black & Grey Box Testing, API Testing (Postman), Firebase / NoSQL, n8n, UX/UI Audit, Selenium, Python (PyTest), Scrum.

Ingeniería de Calidad: IATF 16949, Root Cause Analysis (RCA), Lean Sigma, Gestión de Riesgos, Core Tools, 5S, Kaizen.

Me entusiasma aplicar mi experiencia en sistemas complejos para robustecer el software que mueve al mundo.

* 🚗 **Áreas de interés:**  interés en fortalecer mis conocimientos en seguridad funcional bajo ISO 26262, metodologías HARA y clasificación ASIL, ADAS, conectividad en vehículos, pruebas de API, Testing movil o web y automatización e integración continua.
